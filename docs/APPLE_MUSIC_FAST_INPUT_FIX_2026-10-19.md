# Apple Musicの2倍速事前解析の入力修正

2026-10-19。2倍速の入力を修正し、許可済みのApple Music実音で短区間比較と全曲解析を確認しました。配布用の`dist/MusicPrayer.app`へ反映して起動し、曲一覧・選択・再生位置・音量の保存値が維持されることも確認しました。

## 対象と変更前

依頼は、曲を一覧へ追加した時に無音で2倍速解析し、ローカル曲と同じ解析処理で得た結果を保存・再利用することです。一覧から曲を外した時は結果も削除します。

以前の2倍速検証では、音程補正を切った再生音を取得し、サンプルレートを半分として解析器へ渡していました。この入力で高音域が弱くなり、歌声の判定値が下がることは、既存の原因確認記録で確認済みです。その修正を終えず、通常速度で事前解析を実装した状態から変更しました。

## 変更後

内部再生を`playbackRate=2`、`preservesPitch=true`に設定し、再生中も設定を確認します。既存のCoreAudioタップを`.muted`にし、音声はメモリ内へ取得します。

`AppleMusicTimeExpansion`が音程を変えずに元の長さへ戻します。デバイス出力のないオフライン処理で`AVAudioUnitTimePitch`の`rate=0.5`、`pitch=0`、`overlap=3`を使います。サンプルレートの表示値は変更しません。

元の長さへ戻した音を、既存の`AppleMusicAnalysisInput`、`MusicUnderstandingSession`、`MusicAnalyzer.convert`へ渡します。解析結果の時刻やBPMを後から2倍・半分に書き換える処理はありません。全曲分を通常再生用の固定長キューへ一度に流さず、解析器が要求した分だけ渡します。

取得開始時のPlay待ちで先頭に静音が入るため、自然終端では`(曲の長さ−取得開始位置)÷2`より長い分を先頭から除きます。音量の閾値で曲の静音を削る処理ではありません。終了の検出は既存の50msポーリングによるため、終端後のタップフレームが少量入る場合があり、サンプル単位の同期を保証する処理ではありません。

完了した結果の保存、再利用、一覧から削除した時の破棄には既存の保存処理を使います。中断・終了時は内部再生を止め、通常速度へ戻してから無音化を解除します。通常の再生操作は、この片付けが終わってから進みます。

選曲、歌詞、通常再生、出力先、ビジュアライザーの表示仕様は今回の変更対象に含めていません。

## 実音での確認結果

Wink「愛が止まらない ~Turn it into love~ (Remastered 2018)」、catalog ID `1403236244`を使用しました。検証アプリごとのAudioCapture許可済み記録と、非ゼロの音声データ、タップの`.muted`読み戻しを確認してから測定しました。許可前の0入力は解析方式の評価から除外しています。画面収録・画面共有・マイク入力は使っていません。

最初の修正入力では、以前約9.95kHzで−23dBあった減衰は、約−2.4dBへ改善しました。ただし時間伸長の`overlap=8`ではドラムの活動量が低下しました。Apple SDKの`AudioUnitParameters.h`には、打楽器を含む音を遅くする時は滑らかさを低くした方がよい場合があると記載されています。同じ取得音を8と3で伸長し、同じ通常速度の音と比較しました。

| 歌唱区間30〜70秒の比較 | 通常速度 | 2倍速入力・overlap 8 | 採用したoverlap 3 |
|---|---:|---:|---:|
| 歌声活動量の平均 | 0.722 | 0.697 | 0.699 |
| ドラム活動量の平均 | 0.659 | 0.348 | 0.581 |
| 低音活動量の平均 | 0.607 | 0.507 | 0.502 |
| その他の活動量の平均 | 0.600 | 0.632 | 0.598 |
| 拍数 | 81 | 81 | 81 |
| 小節数 | 20 | 20 | 20 |
| BPM | 119.400 | 119.400 | 119.603 |

表はAppleの解析器が返す活動量の値で、音量や正解率ではありません。3ではドラムが存在する区間も通常速度に近い約40秒全体に戻りました。歌声の大きな低下を避けながら、時間伸長で打音が変わる影響を抑えられたため3を採用しました。等倍との完全一致を合否条件にはしていません。低音などに値の差は残ります。

採用した3の設定で、同じ接続のまま全曲を自然終端まで取得し、既存の6項目の解析を完了しました。取得時間は105.38秒、取得から時間伸長・最終解析まで110.63秒でした。音声取得中は2倍速・音程保持・無音化を維持し、終了時は通常速度・音程保持・停止へ戻しました。

全曲のリズム、調性、構造、ペース、楽器活動、音量の結果を保存しています。全曲検証用の取得には開始準備の静音も含まれます。製品側でその余剰を除く部分は、下記の入力テストで別に確認しました。今回の実音確認はこのMacと1曲を対象にしており、全楽曲の解析値の一致を保証するものではありません。

## テストとアプリへの反映

関連74件のテストが通りました。新しい入力について、人工音源で時間を2倍に戻すこと、音程と10kHzの成分を保つこと、取り消しで処理を終了することを確認しました。準備待ちの余剰フレームを除くことと、正当な曲頭の静音を残すことも確認しています。

64個を超えるバッファを欠けずに渡すこと、サンプルレートを変えないこと、既存の解析処理を通して保存・再読込すること、保存済みなら解析しないこと、一覧からの削除と再追加、通常再生へ譲る処理も関連テストで確認しました。実際の画面操作による「曲追加から保存まで」の通し確認は今回行っていません。

リリース構成のビルド、配布用アプリの署名検証、起動が成功しました。更新後のPIDは40998です。保存済みの`tracks`、`current`、`time`、`volume`は更新前後で一致しました。
