# 全解析結果と全文音声認識の照合 — 2026-10-03

既に取得した全曲320.8秒の6種類のMusic Understanding解析、628音声認識トークン、全64行の元位置・試作位置を再使用した。音源の再解析・音声認識の再実行・新方式の最初からの組立はしていない。今回の追加は、前の組合せ処理が既存の情報を落としていないかを全行で照合した監査である。

## 結論

解析結果と音声認識を合わせることで、歌詞本文に対応する歌唱開始・終了の位置候補は推定できる。前の説明で、確認済み時刻表がないことを理由に、この推定と解析上の整合性の確認までできないように述べたのは不適切だった。独立した実歌唱からの実測誤差と、自動推定は区別して報告する。

前の試作には候補の拾い方と本文の時間対応に問題があった。『全解析を組み合わせた結果』として採用判断に使える段階ではない。前に示した最大0.623秒は元の位置からの移動量であり、この問題を直した後の精度ではない。

## 同じ時系列で照合した情報

各行の最初と最後の音声認識run（文字列に付いた時間範囲）と、既存3方式の開始・終了、認識run内の活動量観測点を調べた。全64行の各時刻に以下の全6種類の文脈を記録した。

| 解析 | 照合した出力と役割 |
| --- | --- |
| Structure | sections/segments/phrases全区間。その時刻がどの区間内か、前後のまとまりを確認 |
| Rhythm | 全拍・全小節・BPM。前後の拍、小節、拍の中の位置、局所間隔を確認 |
| Instrument activity | vocal/drums/bass/otherの全rangesと全activity。存在範囲と強度、歌声の変化と伴奏の変化を同じ時刻で比較 |
| Pace | 全13区間の値と変化。その時刻の音楽の動きの文脈を確認 |
| Key | 全Key区間とtonic/mode。この曲はC majorで全曲一定。変化がないことを確認し、架空の境界支持を作らない |
| Loudness | momentary/shortTerm/integrated/peak。局所音量、全曲の基準音量からの差を確認。全曲代表値のpeak時刻を局所の声の立ち上がりには置き換えない |

公式仕様でも、rangesは楽器を検出した時間範囲、activityは各楽器の強度、SpeechのaudioTimeRangeは文字列に付いた時間情報として提供される。[Apple公式Music Understandingの説明](https://developer.apple.com/videos/play/wwdc2026/253/)、[ranges](https://developer.apple.com/documentation/musicunderstanding/instrumentactivityresult/ranges)、[Speechの時間情報](https://developer.apple.com/documentation/speech/speechtranscriber/resultattributeoption/audiotimerange)

Keyなどの定数も照合から外していない。ただし、全曲で変化しない値を使って個別行の開始点を動かす根拠はない。内部の非公開予測配列は公開Swiftインターフェースに操作APIがなく、この監査では判定の入力に使用しない。

## 全64行で確認した見落とし

各行の最初の認識run全体について、その内部の最小vocal観測点が前後より低い谷となり、後に再上昇するかを同じ規則で調べた。観測点を歌唱の正解時刻として置いていない。

- この谷と再上昇がある：47/64行。
- 谷または谷後の最大隣接上昇の観測点が、前の開始候補にない：38/64行。
- 認識開始から0.50秒以上後の谷があり、その谷または後続上昇の点が候補にない：24/64行。

前の候補処理は認識開始に最も近い前後の歌声イベントだけを選んでいた。長い認識runの後方にある変化を拾っていない。さらに認識開始から離れる移動を罰するため、音響的な支持があっても元の認識開始の近くが選ばれやすい。主案の127/128端は拍の時刻と一致しており、全結果を対等に照合できた方式にはなっていない。

これら38行を『歌詞がずれている38行』とは数えない。歌唱中にも谷・再上昇は発生する。drums/bass/otherの存在範囲と変化、音量、全文の文字順序、区間・拍・Pace・Keyの文脈と合わせて評価する必要がある。

## 64行目の観測例

最後の行『感謝を込めて ありがとう』の『感』の認識runは299.82〜302.16秒。301.593秒にvocalの谷があり、301.643→301.693秒に活動量が0.415→0.684へ上昇している。

この同じ時系列では、drums/bassは0で検出範囲外、otherは存在範囲内でほぼ一定、momentaryは谷から後続して上昇している。sectionは285.361〜306.369秒、segmentは296.357〜306.369秒、phraseは296.357〜303.840秒。上昇点は301.330秒と301.941秒の拍の間にある。Paceは11.58、KeyはC majorのまま。

これらを同時に見ると、長い認識runの途中に新しい歌声の立ち上がり候補があることを支持する。前の候補には301.593秒の谷と301.693秒の上昇が入っていなかった。したがって、前の299.521秒という選択は、この観測を候補として検討した結果ではない。301.693秒を正解の歌唱開始と断定したり、画面の302秒を正解として合わせたりはしていない。
