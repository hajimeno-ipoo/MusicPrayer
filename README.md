# Music Prayer

ローカル音源とApple Musicの曲を、音に反応する立体映像と歌詞とともに楽しむMacプレイヤーです。

リボンと水面反射、カセット、スペクトラム都市の3つのビジュアライザーを選べます。曲の拍・楽器・区間などを解析し、音楽の変化を映像へ反映します。

## 動作環境

- macOS 27以降、Metal対応Mac
- ソースからビルドする場合はXcode 27
- ローカル音源はAVFoundationで読み込める音声ファイル（MP3、WAVなど）
- Apple Musicの利用にはネットワーク接続。契約曲のフル再生にはサインインと有効なApple Musicの契約が必要です

## 起動方法

プロジェクトのフォルダで、次のコマンドを実行します。

```bash
./script/build_and_run.sh
```

Releaseビルドのアプリを作成し、起動します。作成先は`dist/MusicPrayer.app`です。ビルド済みのアプリはFinderから開けます。CodexのRunボタンも同じスクリプトを使います。

## 曲の追加と再生

### ローカル音源

1. 右上の「曲を追加」ボタン、またはCommand＋Oで音声ファイルを選びます。アプリ画面へのドラッグ＆ドロップでも追加できます。
2. 「曲の一覧」を開いて曲を選び、再生ボタンまたはSpaceで再生します。

複数の音声ファイルをまとめて追加できます。音源ファイル自体は変更しません。曲の一覧・選択・再生位置・音量は保存され、次回起動時に復元されます。起動時の自動再生はありません。

### Apple Musicで検索して追加

1. 右上の「Apple Music」を開き、曲名・アーティスト・アルバムを検索します。
2. 検索結果の「一覧に追加」を押します。
3. 表示された「曲の一覧」で曲を選んで再生します。

Apple Musicの曲はローカル音源と同じ一覧に入り、ピンクの「Apple Music」表示で区別できます。曲を追加するだけでは再生中の曲は変わりません。前後の曲、シャッフル、リピートも共通の操作で使えます。

### Apple Music公式画面から追加

検索画面の「Apple Musicを開く」で公式画面へ移動します。追加したい曲を公式画面で再生し、画面上部の「再生中の曲を一覧に追加」を押してください。一時停止中の曲も追加でき、同じ曲は重複登録しません。「プレイヤーに戻る」で一覧の再生へ戻れます。

公式画面のプレイヤーとMusic Prayerの一覧再生は別々に動きます。公式画面での再生・停止・シーク・音量は、公式プレイヤーに対する操作です。追加ボタンは曲情報をMusic Prayerの一覧へ登録します。

配信曲を一覧から外すと、Music Prayerへの登録と、その曲の保存済み解析結果を削除します。Apple Musicのライブラリは変更しません。

## 再生操作

| 操作 | ボタン・ショートカット |
| --- | --- |
| 再生・一時停止 | 再生ボタン、Space |
| 停止 | 「再生」メニューの「停止」、Command＋. |
| 前の曲・次の曲 | 前後の曲ボタン、Command＋左矢印／右矢印 |
| 曲を追加 | 「曲を追加」、Command＋O |
| Apple Musicを開く | 「Apple Music」、Command＋Shift＋M |
| シャッフル・リピート | 下部の各ボタン |
| 音量・ミュート | 音量スライダー、音量アイコン |
| 出力先 | 音量の横の出力先メニュー |
| フルスクリーン | 右上の「フルスクリーン」ボタン |

シークバーはドラッグ中に移動先の映像を表示し、離すと再生位置を変更します。Apple Musicの曲は、再生前や一時停止中にも位置を選べます。Spaceなどの再生ショートカットはプレイヤー画面で使います。Apple Musicの検索・公式画面や文字入力中は、それぞれの画面の操作が優先されます。

出力先を変えると、ローカル音源ではこのアプリの出力先が変わります。Apple MusicではMacの既定の出力先が変わるため、ほかのアプリの音にも影響します。

## ビジュアライザーと外観

右上のビジュアライザーメニューから表示を選びます。

| 表示 | 特徴 |
| --- | --- |
| リボン | 立体的なリボンと水面反射。水面をクリック・ドラッグすると波紋が広がります |
| カセット | ジャケットと曲名を貼った立体カセット。再生中はリールが回り、周囲にスペクトラム、経過・残り時間を表示します |
| スペクトラム都市 | 40棟のクリスタルの建物が音の帯域に応じて伸縮し、楽器や拍に合わせて街路の光と床の反射が変わります |

音量や周波数の動きに加え、解析済みの曲では拍・小節・BPM・楽器の活動・曲の区間・キーを映像へ反映します。一時停止すると動きが落ち着き、余韻や水面の波が収束した後は描画を休止します。

外観メニューでは「ライト」「ダーク」「システム設定に合わせる」を選べます。背景にはLiquid Glassを使い、壁紙や背後のウインドウが透けます。曲の一覧・歌詞編集・解析パネルも選んだ外観に合わせて表示します。macOSの「透明度を下げる」が有効な場合は、ビジュアライザーの背景を不透明にします。

## 歌詞

### ローカル曲に歌詞を登録

1. 曲を選び、右上の「歌詞」を開きます。
2. 本文を貼り付けるか、「ファイルを読み込む」で`.txt`ファイルを選びます。歌詞ファイルをアプリ画面へドロップしても本文を取り込めます。
3. 「適用」を押すと、選択中の曲へ保存し、音声と照合して表示タイミングを生成します。

音声ファイル1つと歌詞ファイル1つを同時にドロップすると、その曲を選んで歌詞編集を開きます。歌詞は「適用」を押すまで保存されず、曲も自動再生しません。「クリア」も編集欄だけを空にし、「適用」を押すまで保存済みの歌詞は変わりません。

タイミングの生成に失敗した場合は、歌詞編集に理由と「タイミングを再生成」を表示します。音声認識が対応していない言語や、このMacで認識モデルを準備できない場合があります。モデルの初回準備にはネットワーク接続が必要になることがあります。

### Apple Musicの歌詞

取得できた歌詞を自動表示します。語ごとの時刻がある歌詞はその時刻を使い、行ごとの時刻だけがある歌詞は音声認識による照合を行います。細かな文字時刻がない行は、歌声の解析などを使った表示用の進行で色を変えます。表示用の進行は、認識できた文字の発音時刻とは区別されます。時刻のない本文は白で表示します。

音声認識では、配信された歌詞の言語情報と本文の各行・混在部分から認識する言語を集めます。全文を一言語に固定せず、各言語で同じRAM音声を認識し、既存の照合処理で各行に合う結果を使います。一つの言語や行で認識できなくても、ほかの行の有効な結果と公式の時刻は保ちます。

解析したタイミングは保存して再利用します。音声認識処理が失敗した場合は、理由と「解析をやり直す」を表示します。上段の「歌詞」ボタンはローカル曲への登録用で、Apple Musicの歌詞は自動取得します。

Apple Musicが歌詞の未配信を明示した曲は「解析済み・歌詞なし」と表示します。取得失敗とは区別し、取得失敗時は「歌詞を再取得」からやり直せます。音楽解析の結果と停止位置は保ちます。曲一覧に歌詞同期の行数などの内部情報は表示しません。

### 歌詞フォント

右上の歌詞フォントメニューで「システムフォント」「Furifont Sans VF」「Rubifont Sans VF」を切り替えられます。選択は保存され、ローカル曲とApple Musicの歌詞に共通で使われます。Rubifont Sans VF 0.6.19は、日本語の読みと、収録された英単語のカタカナ読みを表示します。

Rubifontでは、歌詞の解析・準備中に送り仮名と文脈の対応表を辞書と照合し、「来ない」の「こ」、「来る」の「く」などを選んで保存します。再生中は保存結果を使い、辞書での選別は行いません。「行った」「止めた」のように読みを一つに決められない語は、既定の表示を使います。既存の解析に読み指定がない場合や辞書の版が古い場合は、有効な歌詞時刻を再利用して読み指定を更新します。「あの娘」は「あのこ」、「1つ・１つ」は「ひとつ」、「2人・２人」は「ふたり」を選びます。「街と人が」の「人＝ひと」、「想い出を」の「出＝で」にも対応します。「2つ・２つ＝ふたつ」「不満の声＝ふまんのこえ」「金のハンドル＝きんのハンドル」も対応表で選びます。「胸の鼓動焼きつけろ」「あの時感じた」と、AHの「アー」は同梱フォントの辞書を更新しています。本文と文字時刻は変更しません。

## 曲の解析

右上の「詳しい解析」で、次の内容を確認できます。

| 項目 | 表示内容 |
| --- | --- |
| 構造・区間 | 曲の区切り、拍、小節、BPMなど |
| 活動量・楽器 | 歌声や楽器の活動の変化 |
| 音量・ピーク | 音量やピークの推移 |

ローカル音源はMac内で解析し、結果を保存して再利用します。音楽解析や歌詞の照合のためにローカル音源を外部へ送信しません。取得できなかったBPMやキーは「未取得」として扱います。解析中も再生できます。

Apple Musicは、一覧へ追加した未解析の曲を最大2曲ずつ無音で事前解析します。3曲目以降は順番に処理します。曲の一覧と選択中の曲のメイン画面に進捗を表示し、完了後は「解析済み」やBPM・キーを表示します。公式画面へ移動したり、別の曲を追加したりしても、登録済みの曲の解析は続きます。

事前解析が終わる前も、再生音の音量や周波数に合わせて映像が動きます。通常再生で取得した解析結果も、曲を最後まで再生すると保存します。途中で止めた未完の解析は確定保存しません。

### Apple Musicの音声取得

配信音をビジュアライザーと解析へ使うため、macOSからシステム音声取得の許可を求められることがあります。アプリ自体は画面を取得せず、取得した音声を録音ファイルとして保存しません。

通常再生の音量を下げても映像の反応を保つよう補正しますが、音量0・ミュートでは音を取得できず、反応が止まります。一時停止中は音声取得も停止します。

## 保存先

アプリの保存先は`~/Library/Application Support/com.hazimeno.MusicPrayer/`です。

| 保存先 | 内容 |
| --- | --- |
| `queue.json` | 曲の一覧、選択、再生位置、音量 |
| `Analysis/` | ローカル音源の解析結果 |
| `Lyrics/` | ローカル曲に登録した歌詞と表示タイミング |
| `AppleMusicAnalysis/` | Apple Musicの解析結果と歌詞の表示タイミング |

外観と歌詞フォントの選択はアプリの設定として保存します。ローカル音源の解析は音源の内容から照合し、Apple Musicの解析は曲IDや長さなどから照合します。

## 利用上の注意

Apple Musicの検索・再生・歌詞取得は公式サイトの構成に依存します。Apple側の変更によって接続や歌詞の取得に修正が必要になる場合があります。サインインしていない場合はプレビュー再生になります。

先に予約した次曲を再生中に変更すると、音声のつなぎ直しによる短い途切れが生じる場合があります。映像は60fpsを要求しますが、実際の描画回数はディスプレイとGPUの性能に応じます。

Rubifont 0.6.17では「声聞」は通常「こえ・き」、別読みの2番は「しょうもん」です。「あなたの声聞きたくて」は文脈による指定なしで表示します。0.6.16の保存済みの読み指定は再生成します。

Rubifont 0.6.18で「1日・１日＝いちにち」「人生楽ありゃ苦あり＝じんせいらくありゃくあり」「声で＝こえで」「楽に＝らくに」と「ゴミの中走ってく」の中・走の読みを補いました。英語candy・pretty・dollも追加しています。通常の1つ＝ひとつは保ちます。

Rubifont 0.6.19では「人ゴミ」の「人＝ひと」を文脈表で選びます。「今朝もミニのスカートで 人ゴミの中走ってく」の人・中・走に、それぞれ「ひと・なか・はし」を表示します。0.6.18の読み指定は再準備し、歌詞本文と文字時刻は保持します。
